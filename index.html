Các Gói Dịch Vụ Cung Cấp

Được tối ưu riêng cho các website cá nhân, doanh nghiệp nhỏ và startup.

Rà soát Lỗ hổng Website

Quét toàn diện các lỗi OWASP Top 10 phổ biến (XSS, SQLi cơ bản, cấu hình sai file/header) và gửi báo cáo hướng dẫn fix lỗi.

Bàn giao: 2-3 ngày Từ 500.000đ

Gỡ Malware & Cấu hình WAF

Tìm và xóa bỏ webshell, mã độc chèn trái phép trên mã nguồn WordPress/PHP. Cấu hình Cloudflare WAF chống bot độc hại.

Bàn giao: 1-2 ngày Từ 400.000đ

Cấu hình DNS & Security Headers

Thiết lập bản ghi SPF, DKIM, DMARC chống giả mạo email và cấu hình đầy đủ HTTP Security Headers chuẩn bảo mật cao.

Bàn giao: 1 ngày Từ 300.000đ

Sửa lỗi Web & Fix Bug

Khắc phục lỗi giao diện (CSS/Responsive), xử lý lỗi logic JavaScript trên trình duyệt hoặc sửa lỗi xử lý form PHP cơ bản.

Bàn giao: Nhanh trong ngày Từ 200.000đ

Viết Script Tự động hóa

Lập trình Python script cào dữ liệu web (Web Scraping) hoặc tạo bot Telegram/Discord thông báo sự kiện, giám sát hệ thống.

Bàn giao: 2-4 ngày Từ 400.000đ

Phân tích File Log Website

Đọc và phân tích file log (Apache/Nginx access log) để lọc ra các IP có hành vi tấn công, rà quét hoặc brute-force hệ thống.

Bàn giao: 1 ngày Từ 300.000đ
