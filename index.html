Các Gói Dịch Vụ Cung Cấp

Được tối ưu riêng cho các website cá nhân, doanh nghiệp nhỏ và startup.

Kiểm thử Lỗ hổng Web (Pentest)

Quét và kiểm thử thủ công các lỗi OWASP Top 10 (XSS, SQLi, CSRF, IDOR, phân quyền) và xuất file báo cáo tư vấn sửa lỗi chi tiết.

Bàn giao: 2-3 ngày Từ 190.000đ

Cấp cứu Malware & Webshell

Rà soát triệt phá mã độc, webshell, script ẩn trên nguồn WordPress/PHP. Khôi phục trang web về trạng thái sạch an toàn.

Bàn giao: 1-2 ngày Từ 150.000đ

Phân tích File Log & Truy vết

Xử lý dữ liệu Log (Nginx/Apache/Cloud Audit) để bóc tách IP nghi vấn, hành vi dò quét hệ thống hoặc tấn công brute-force.

Bàn giao: 1 ngày Từ 120.000đ

Gia cố Server & Cloudflare WAF

Thiết lập HTTPS/SSL mã hóa cao, cấu hình HTTP Security Headers (CSP, HSTS) và thiết lập quy tắc Cloudflare WAF chặn bot.

Bàn giao: 1 ngày Từ 120.000đ

Bảo mật DNS & Email Domain

Cấu hình các bản ghi SPF, DKIM, DMARC chuẩn cho tên miền. Giúp email không chui vào hòm thư Spam và chống mạo danh.

Bàn giao: Trong ngày Từ 90.000đ

Thiết kế Web & Script Tự động

Lập trình Landing Page/Website tối ưu, viết script Python/JS cào dữ liệu web hoặc dựng Bot Telegram cảnh báo tự động.

Bàn giao: 2-3 ngày Từ 150.000đ
